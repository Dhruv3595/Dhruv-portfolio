# Dhruv Pandya — Developer Portfolio

Personal portfolio website built with **React.js**, **Tailwind CSS**, and **Framer Motion**, showcasing software engineering projects, data science applications, and professional experience.

---

## ⚡ Highlights & Features

- **Modern Luxury Dark Theme**: Custom dark aesthetics with ambient glow cards and responsive glassmorphic UI elements.
- **Ultra-Fast Performance**: Fully optimized static image assets (compressed from >8MB to ~220KB) and instant lazy loading.
- **Interactive Component Animations**: Smooth viewport reveal effects powered by Framer Motion and custom intersection observer hooks.
- **Full-Stack & Data Science Showcase**: Featured projects ranging from React full-stack tools to AI/ML data science applications.
- **Functional Contact Form**: Direct form submission integration using Formspree and one-click social channels (Email, LinkedIn, GitHub, WhatsApp).

---

## 💻 Getting Started Locally

To run this portfolio locally on your machine:

1. **Clone the repository**:
   ```bash
   git clone https://github.com/Dhruv3595/Dhruv-portfolio.git
   cd Dhruv-portfolio
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start development server**:
   ```bash
   npm run dev
   ```
   Open `http://localhost:5173` in your browser.

4. **Build for production**:
   ```bash
   npm run build
   ```
   The production-ready output will be generated in the `dist/` directory.
